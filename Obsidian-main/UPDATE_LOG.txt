RELEASE 3 UPDATE NOTES
2026-09-08
Version: 0.0.1-release-3 (unchanged)

CONFIG LOAD COMPLETION
SaveManager:OnConfigLoaded(callback) runs once after a successful load, including
options, adapters and theme finalization. It also covers LoadJSON and autoload.
Register it before calling LoadAutoloadConfig. The callback receives the report:
ConfigName, Source (JSON, Load or Autoload), Status, Applied, Skipped and Missing.
A failed load or internal rollback does not fire it. No configured autoload also
does not fire it: initialize your view with defaults before requesting autoload.
Callback errors are collected in report.ListenerErrors; they do not undo a load.
The registration returns a function that disconnects the callback.

    local disconnect = SaveManager:OnConfigLoaded(function(report)
        refreshCatalog()
    end)
    SaveManager:LoadAutoloadConfig()
    -- Call disconnect() when the consuming view is destroyed.

HIDDEN VALUES
Library:AddHidden(id, default, info) stores state without creating a GUI object.
Groupbox:AddHidden has the same arguments. Read Options[id].Value or GetValue().
Use SetValue(value) to change it and OnChanged(callback) to observe changes.
Strings, booleans, numbers and JSON-compatible tables can be saved. Keep IDs
unique across controls and hidden values. Do not store Instances or functions.

    local skin = Library:AddHidden("SelectedSkinId", "default")
    skin:SetValue("blue")

OPTION VERSIONS
Set ConfigVersion in control info, or call option:SetConfigVersion(2).
An older saved option, including one without a version, uses the default captured
when the control was created. A subsequent save stores the new version.
Equal or newer saved versions preserve the saved value. Options without an
explicit ConfigVersion keep their previous behavior. Increment only when a
specific option must reset. This is not a global config reset or file migration.

    local skin = Library:AddHidden("SkinId", "default", { ConfigVersion = 2 })

SELECTION AND VISIBILITY
Dropdown:GetSelected() returns a fresh array. Multi selection follows Values
order for array-backed dropdowns; dictionary-backed selections are sorted by
key type and text. Single selection returns one entry, or an empty array.

    local selected = Options.Hitboxes:GetSelected()
    Options.Thickness:SetVisible(false)
    Options.Accent:SetVisible(false)

Key pickers, color pickers and tabboxes now expose SetVisible. Hiding a picker
closes its popup. Hiding a dropdown also closes its popup. Dependency containers
remember manual hiding when dependencies refresh; showing one still respects
its dependencies. Hidden options remain invisible regardless of SetVisible.

WINDOW CORNERS
The outer window and background image retain the full corner radius when the
radius changes from 0 or 1. Previously they could receive a half-radius value.
Radius updates now use whole, non-negative pixels.

UPDATING
Update Library.lua, Library.d.luau and addons together from the latest revision.
The release label remains release-3, so check revision changes as well as the
label. Keep control IDs stable and create controls and adapters before loading.
See GUIDE.md for the full setup. Device rendering still needs a Roblox check;
local regression tests cover config behavior and existing layout contracts.
2026-09-08 - CATALOG AND EDITOR CONTROLS
Version remains 0.0.1-release-3.

Added AddImageGrid(id, info), backed by ImageGallery. Register the loaded module
with Library:RegisterImageGrid(ImageGallery). Existing search, paging and styling
remain available. Set DraggableItems=true and DragType="Sticker" for sticker cards.

Added AddItemSlots(id, info). Five sticker slots are provided by default; pass
Slots={"Charm1","Charm2","Charm3","Charm4"} for charms. A matching DragType accepts
items from a grid. Assign(slotId, item) also supports tap-based workflows;
Assign(slotId, nil) clears a slot. Configs store IDs, not images or model Instances.

Added AddSliderGroup(id, info). X, Y, Rotation, Scale and Wear share a compact row
and wrap on narrow screens. Sliders can be replaced with custom fields. SetValue
accepts a partial field map. Config IDs use groupId/fieldId. Use a hidden map for
per-slot transforms when one row edits several slots.

AddViewport now accepts Model as an alias for Object and exposes Zoom(amount).
It works inside popups, preserves previous scrolling state and releases pinch
scroll locks on cancellation. Interactive=true enables rotation and zoom.

Added Window:AddPopup and dialog:AddPopup. Editors can open above a catalog.
Escape closes the top popup; closing a parent also closes its children. Long
content scrolls inside the available window area. Existing AddDialog calls work.

The Preview tab demonstrates the controls. GUIDE.md includes setup, callback
arguments, persistence rules and short examples for each API. Local tests cover
slot validation, drops, cancellation, narrow slider rows and popup lifetimes.
Real device gesture and rendering checks still need Roblox.
2026-09-09 - WISHLIST FOLLOW-UP
Version: 0.0.1-release-3, unchanged.

Fixed late catalog replacement, including SetItems(Gallery.Items), without replacing
card frames. Hiding groups closes child context menus. Search now includes tooltips
and dropdown choices and safely skips hidden options with no GUI.

Stale dropdown selections recover to a valid default. Load reports list replacements
in AdjustedIds and version resets in ResetIds. Hidden ConfigVersion behavior is
covered by regression tests. Save=false and option:SetSave(false) exclude individual
options from saving and loading. SaveManager:GetConfigs() lists available names.

Added AddSection, Library:SetValues and Library:OnConfigChanged. Presets defer
related dependency updates to one pass. The change listener receives one batch
report; it is separate from successful config-load completion.

Added CallbackOnRelease for expensive slider callbacks, touch-hold tooltips,
attachment-point viewport markers, AddLazyTab and AddKeybindProfile. See GUIDE.md
for signatures, error behavior and short usage examples. Preview includes demos.

Live notifications recalculate after a font change. Existing registry-based theme
updates, bounded text measurement caching, reusable gallery cards and custom slider
group fields were checked rather than replaced. Save/load builds cold lazy tabs
before persistence so values cannot disappear from a config.

Update Library.lua, Library.d.luau, SaveManager and ImageGallery together to the latest
revision. Local tests pass; mobile gesture/rendering and performance measurements
still require a Roblox session on the intended device.
2026-09-10 - COMPACT OVERLAYS
Version stays 0.0.1-release-3.

Addon headers now use a compact 28-pixel layout. Icon badges and subtitles are
optional; Compact=false retains the larger header. Flat dashboard sections remove
the extra border and repeated padding. A single section no longer repeats a title;
multiple sections keep their headings.

Standalone dashboards can fit their height to the displayed rows. Use AutoHeight=true
for spectator lists, with MaxContentHeight to cap long lists. Explicit window heights
remain fixed unless auto height is requested. GUIDE.md includes a short setup example.

Watermarks use smaller type and tighter padding with a thin outline. Added Compact,
Minimal and Classic presets through SetWatermarkPreset. Text and font inheritance
remain unchanged. Preview includes a spectator-list demo and preset switching.

Tests cover compact and classic headers, content resizing, section headings and
fixed-size compatibility. Update Library.lua and DashboardWindow.lua together with
the latest types and examples. Real Roblox rendering still needs an in-game check.
